Dip-buy BTC trading bot: buys cbBTC after a ≥1% 60-minute dip and sells the recovery (+1.2% take-profit, −1.2% stop, 240-bar hold cap). Python 3.13, standard library only, deterministic. Dev window: net PnL +$24.54.

## Run it

```sh
python3 main.py
```
